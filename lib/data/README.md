# City centers

`cities.json` is derived from [GeoNames cities15000](https://download.geonames.org/export/dump/cities15000.zip)
and [country names](https://download.geonames.org/export/dump/countryInfo.txt), retrieved 2026-09-17.
Each row contains name, ASCII name, country, latitude, longitude. Coordinates are
approximate city centers, never personal addresses. Duplicate city/country names
at different coordinates are not resolved. Unsupported locations remain unmapped.

GeoNames data is licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Attribution is also shown on the map. To refresh, retain these five columns from
the tab-separated exports; do not add profile or user data to this file.
